# Agent notes

Preserve the browser-only agent boundary, explicit write authorization, exact ticket identity, attachment reading, later-correction precedence and revision checks. Failed form submissions must remain visibly unsaved. Keep restricted ticket details inaccessible. Use synthetic fixtures only. Do not commit keys, workspace state or capture files. A scripted AI SDK model verifies the tool loop but is not evidence of live provider behavior or Firedrill integration.
